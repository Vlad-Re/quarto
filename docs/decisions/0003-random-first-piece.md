# 0003. Випадкова перша фігура

Статус: прийнято для v1.0.

Контекст: алгоритми мають бути детерміновані, але однакові партії нецікаві.

Рішення: першу фігуру бот обирає випадково.

Обґрунтування: інвертування будь-якого атрибута переводить набір фігур сам у себе й зберігає виграшні лінії, тож на порожній дошці всі 16 фігур стратегічно рівноцінні. Випадковість не впливає на силу гри.

Альтернатива: завжди віддавати ту саму фігуру.
