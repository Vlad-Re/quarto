# 0018. Вікно наслідує tk.Frame, затримка через schedule

Статус: прийнято.

Рішення: клас вікна наслідує `tk.Frame`; вікно має метод `schedule(ms, callback)` поверх `after`, презентер tkinter не імпортує.

Альтернативи: композиція; виклик `after` з презентера.

Наслідки: приклади з туторіалів підходять напряму; презентер відокремлений від tkinter (separation of concerns).
