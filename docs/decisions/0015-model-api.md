# 0015. Інтерфейс моделі

Статус: прийнято.

Рішення: вільні функції `new_game`, `place`, `give`, `outcome`; результат `Win | Draw | None` обчислюється з дошки; бот повертає `Move(cell, piece | None)`; недозволений хід — `IllegalMove`.

Альтернативи: методи на dataclass; одна функція `apply`; результат як поля стану або Enum.

Наслідки: результат не може розійтися з дошкою; `apply` можна додати пізніше поверх двох функцій.
