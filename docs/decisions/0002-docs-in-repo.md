# 0002. Документація в репозиторії

Статус: прийнято.

Контекст: вимоги й рішення мають відповідати тій версії коду, для якої писалися.

Рішення: документація зберігається в `docs/` у форматі Markdown і версіонується разом із кодом. Рішення фіксуються короткими записами в `docs/decisions/`.

Наслідки: на кожному тезі зафіксовані і код, і вимоги.
