# 0006. GUI-бібліотека — tkinter

Статус: прийнято.

Контекст: перша гра автора; потрібні кнопка Reset, рядок статусу, діалог підтвердження, затримка ходу бота; Python 3.14.

Рішення: tkinter.

Альтернатива: pygame-ce — ігровий цикл і малювання, але без кнопок і діалогів; підтримку Python 3.14 треба перевіряти окремо.

Наслідки: один потік, керований подіями; затримка — таймером tkinter; для чіткості при масштабуванні 125% потрібне налаштування DPI.
