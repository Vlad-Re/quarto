# 0019. Без DPI-awareness у v1.0

Статус: прийнято для v1.0, змінити пізніше.

Контекст: Windows 11, масштабування 125%, вимога не залежати від масштабування.

Рішення: нічого не вмикати; Windows масштабує вікно сам.

Наслідки: пропорції завжди однакові без жодного коду, але зображення трохи розмите. Пізніше — увімкнути DPI-awareness.
