# 0001. Git і приватний GitHub

Статус: прийнято.

Контекст: потрібне керування версіями коду й документації та резервна копія.

Рішення: Git, одна гілка `main`, приватний репозиторій на GitHub. Коміти англійською з префіксами (`docs`, `feat`, `fix`, `test`, `refactor`, `chore`). Релізи позначаються тегами.

Наслідки: історія комітів показує розвиток проєкту. Репозиторій може стати публічним пізніше.
