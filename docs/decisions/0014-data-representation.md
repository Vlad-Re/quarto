# 0014. Представлення даних

Статус: прийнято.

Рішення: Rust-подібний стиль без наслідування; `Piece` і `Cell` — NewType над int; фігура в бітовій нотації; дошка — tuple з 16 клітинок; доступні фігури — frozenset; стан: дошка, фігури, поточна фігура, сторона (`FIRST`/`SECOND`), дія (`PLACE`/`GIVE`); без історії ходів.

Альтернативи: фігура як dataclass з bool чи Enum; дошка 4×4 чи dict; бітборди (кандидат на пізніше); одна Enum на чотири фази.

Наслідки: швидка перевірка ліній побітовими операціями; модель не знає, хто бот.
