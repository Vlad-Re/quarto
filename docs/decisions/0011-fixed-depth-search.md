# 0011. Фіксована глибина пошуку у v1.0

Статус: прийнято для v1.0. Замінює 0004 на цю версію.

Контекст: два тижні на завдання — перший на оціночну функцію, другий на дерево пошуку. Демонстрація проміжна.

Рішення: мінімакс з фіксованою глибиною `MINIMAX_DEPTH` і оцінкою в листках; глибина підбирається вимірюванням під 3.5 с. Жадібний бот — запасний варіант.

Альтернативи: мінімакс лише в ендшпілі; мінімакс лише в тестах.

Наслідки: хід відтворюваний (не залежить від швидкості машини); на початку партії бот бачить неглибоко.
