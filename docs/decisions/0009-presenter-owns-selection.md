# 0009. Презентер звертається до вікна напряму і тримає стан вибору

Статус: прийнято для v1.0.

Рішення: презентер викликає методи класу вікна tkinter напряму, без Protocol. Рамку першого кліку по фігурі пам'ятає презентер; вікно лише малює її там, де скажуть.

Альтернатива: Protocol «вікно» для тестування презентера з фейковим вікном — після v1.0.

Наслідки: правило двох кліків можна перевірити тестом; тестування самого презентера у v1.0 обмежене.
