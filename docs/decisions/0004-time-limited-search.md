# 0004. Час як критерій зупинки пошуку

Статус: замінено рішенням 0011 для v1.0; повернутися після v1.0.

Контекст: потрібна глибина пошуку сильно відрізняється між початком і кінцем гри; гравець не повинен довго чекати.

Рішення: пошук обмежується часом, не більше 3.5 с.

Альтернативи: фіксована глибина (не підходить — різні позиції потребують різної глибини); бюджет вузлів з часом як запобіжником (кандидат для v2).

Наслідки: обраний хід може залежати від швидкодії машини.
