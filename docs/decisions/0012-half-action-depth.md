# 0012. Одиниця глибини — півдія

Статус: прийнято.

Рішення: один рівень дерева — один `place` або один `give`.

Обґрунтування: рівень = один виклик моделі; до 16 або 15 гілок замість 240; альфа-бета відсікає раніше.

Наслідки: дві дії поспіль робить одна сторона (макс, макс, мін, мін). Жадібний бот — глибина 3.
