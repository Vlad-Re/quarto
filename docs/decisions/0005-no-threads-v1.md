# 0005. Без потоків у v1.0

Статус: прийнято для v1.0.

Контекст: Reset під час розрахунку бота потребує потоку або розбиття обчислень; це додає складності й ризиків.

Рішення: у v1.0 потоків немає. Під час розрахунку бота (до 3.5 с) вікно не реагує, Reset недоступний.

Наслідки: Reset під час розрахунку переноситься у v2.
